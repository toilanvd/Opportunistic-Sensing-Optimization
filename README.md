***	Test configuration for general scenario:

The first line contains three numbers: p, q, and r.

The second line contains the number of bus routes, n.

Following this are the bus routes. For each route:

- The first line indicates the total number of vertices (inflection points) for both paths.

- The next line specifies the number of vertices for each individual path.

- This is followed by the coordinates of these vertices.

The last part consists of a number c, representing the number of important cells, followed by the bottom-left coordinates of those c cells.

***	Test configuration for simplified scenario:

The first line contains three numbers: p, q, and r.

The second line contains the number of bus routes, n.

Then come the bus routes. For each route:

- The first line specifies the number of vertices (inflection points).

- The following lines provide the coordinates of these vertices.

The last line contains an integer c, representing the number of important cells, followed by the bottom-left coordinates of those c cells.
